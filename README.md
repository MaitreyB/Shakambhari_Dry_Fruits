# Shakambhari Dry Fruits & Foods 🌿

A modernized, high-converting digital storefront and corporate gifting showcase for **Shakambhari Dry Fruits & Foods** (Pune, India). Sourcing premium dry fruits, organic seeds, exotic berries, and pure Grade A Kashmiri Saffron directly from trusted farms at wholesale rates.

---

## ✨ Features

- **Sensory & Modern UI**: Bespoke dark aesthetic with warm champagne gold accents, subtle analog noise texture, and ambient floating gradient orbs.
- **Dynamic Weight & Pack Selector**: On-card interactive toggles for `250g`, `500g`, and `1kg` packs with dynamic price recalculation.
- **Live Search & Dietary Goal Filtering**: Real-time debounce search across 44 products, descriptions, and health benefits (`Heart Health`, `Brain Function`, `High Protein`, `Immunity`, `Antioxidants`).
- **Interactive Quick-View Modal**: Detailed product inspection with high-res photography, FSSAI quality verification, nutrition highlights, and quantity steppers.
- **Direct WhatsApp Checkout Engine**: Formatted itemized order drafting with quantities, pack sizes, totals, and delivery details sent directly to WhatsApp with zero checkout friction.
- **Free Delivery Progress Bar**: Animated cart delivery threshold bar encouraging higher order values for free Pune delivery.
- **Editorial Storytelling Split**: Parallax image narrative highlighting 15+ years of direct farm sourcing and wholesale heritage.
- **Stats Counter & Scroll Progress**: Fluid 60fps Framer Motion scroll progress indicator and count-up metrics strip.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS Design Tokens (Strict typography, glassmorphism, responsive grid)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/MaitreyB/Shakambhari_Dry_Fruits.git

# Navigate into the project directory
cd Shakambhari_Dry_Fruits

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
